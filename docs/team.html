상태 보고 (현황판이 읽는 방법)

현황판은 노트북 화면에 직접 연결되어 있지 않습니다. Codex/agy가 맡은 이슈에 STATUS: 댓글을 남겨야 카드가 갱신됩니다. 시작·막힘·완료 때와 최소 30분마다. MATLAB 담당도 git 없이 이 댓글만 남깁니다. 형식은 PROMPTS.md 0.1절, ONBOARDING.md.

gh issue comment <이슈번호> --body "$(cat <<'EOF'
STATUS: 🟢 진행 중
작업: <한 줄>
진행률: 30%
막힌 점:
다음:
EOF
)"

첫 줄은 STATUS: 🟢 진행 중 / 🔴 막힘 / 🟡 리뷰 대기 / ✅ 완료 중 하나. 본문 첫 줄은 반드시 STATUS:로 시작합니다. 막히면 즉시, PR을 열면 리뷰 대기, 끝나면 완료로 바꿉니다.
