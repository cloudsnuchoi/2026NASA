DB 테이블 (2026-11-15 확인)

서비스 DB는 협업 도구와 분리합니다. 아래는 라이브 DB에서 행이 있는지 확인한 결과입니다.

테이블역할상태
fieldsCSB 필지, 기하(EPSG:4326)적재됨
field_crop_historyCDL 필지 작물 이력적재됨
field_soilSSURGO 토양적재됨
field_ndvi_hlsHLS NDVI적재됨
field_et_openetOpenET 월 ET적재됨
vision_resultPrithvi 추론 (20필지, 2024)적재됨
county, county_crop_share, county_yield카운티 경계·작물 비율·NASS 수량적재됨
county_weather_daily, county_imerg_daily, county_nldas_monthly, county_smapPOWER·IMERG·NLDAS-2·SMAP 카운티 시계열적재됨
county_scenario_yearGEOS-S2S·NEX-GDDP 시나리오적재됨
evidence_chunk근거 인용·DOI (pgvector)0행 → 대체 경로 (insufficient_evidence)
field_season, field_dekad, climate_daily, climate_annual, scenario_climate, strategy_score, backtest_result, calibration_param, data_sourceSOT 초안 테이블0행 · 미사용(향후). MC·백테스트는 요청 시 계산
