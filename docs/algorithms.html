AI 네 층과 알고리즘

라이브 엔진은 규칙·지수 스코어링 + 몬테카를로 물수지 + CVaR입니다. 강화학습과 미세조정은 하지 않습니다. LLM은 숫자를 만들지 않고, MATLAB은 오프라인 보정만 합니다.

요약 표는 AI 모델 탭에 있습니다. 이 페이지는 알고리즘 카드·수식입니다.

수식은 문서에 적힌 최소 규격입니다. 축 가중치의 숫자 기본값은 문서에 고정되어 있지 않아 여기서 지어내지 않습니다. 슬라이더가 가중만 바꿉니다.

AI 네 층

Prithvi 추론만

HLS 6밴드×3시점 → vision_result (작물·맨땅, CDL 일치율). 실패 시 CDL. 라이브 경로 아님(배치). 담당 Hylē.

L3 시뮬레이션

7축 + MC + CVaR

피처+슬라이더 → 전략 카드, P10/P50/P90, CVaR. 라이브는 사전 계산 + 재가중. Python/NumPy, FastAPI. 담당 Hylē.

L4 설명

LLM tool-call + RAG

API JSON + evidence_chunk → 설명 문장과 DOI. 숫자 생성 금지. 임베딩 실패 시 pg_trgm. 라이브. 담당 Hylē.

알고리즘 목록

규칙·지수 7축 점수 score7

L3화면 S4Hylē · model_api/
입력 필지·카운티 피처, 작물 특성(문헌 Kc 등), 전략 A–D
출력 축별 점수 0–1, 슬라이더 가중 합, 기준 A 대비 %

일곱 축: 질소 순환, 침식, 유기물, 병해충 차단, 물 사용, 사료 가치, 시장 적합성(수량 옆축은 선택). 확정 kg/ha는 내지 않습니다.

\[ S = \sum_{k=1}^{7} w_k s_k, \quad s_k \in [0,1], \quad \sum_k w_k = 1 \]

reweight: 우선순위 슬라이더(물·토양·회복력·소득/시장)는 가중 \(w_k\)만 바꿉니다. 원점수 \(s_k\)와 분포는 유지합니다. 단일 정답으로 순위를 강제하지 않습니다. 물 제한이면 물 축 가중을 올립니다.

몬테카를로 물수지 wb_mc

L3화면 S4·S5Hylē · 사전계산
입력 POWER 일 기후(1991–2020 또는 적재 창), IMERG, SSURGO AWC, FAO-56 \(K_c\), 시나리오 이동
출력 생육기 물 부족(mm), 스트레스 일수, 겨울 맨땅 일수 → P10/P50/P90

연 단위 재표본 \(N=500\)–\(1000\). 일 물수지와 증발산:

\[ SM_t = SM_{t-1} + P_t - ET_{c,t} - R_t, \qquad ET_c = ET_0 \times K_c, \qquad \mathrm{cap} = \mathrm{AWC} \times z_{\mathrm{root}} \]

\(ET_0\)는 FAO-56(fao56, POWER). \(K_c\)는 작물·생육 단계 문헌 범위. 용량을 넘으면 유출/배수 \(R_t\). MATLAB은 계수만 calibration_params.csv로 넘깁니다.

CVaR와 분위 cvar

L3화면 S4·S5Hylē
입력 몬테카를로 표본(물 부족, 스트레스 일수 등)
출력 P10, P50, P90, 하위 10% 평균(CVaR). 단위는 응답 unit

회복력·꼬리 위험을 봅니다. 하위 10% 평균:

\[ \mathrm{CVaR}_{0.10}(X) = \mathbb{E}\!\left[X \mid X \le q_{0.10}(X)\right] \]

P10/P50/P90은 같은 표본의 경험적 분위입니다. 화면의 %는 “기준 전략 A 대비 상대 지수, 보장값 아님”과 범위를 함께 보여 줍니다.

CDL/CSB 백테스트 backtest_cdl

검증화면 S5 · /validation/backtestHylē, 김윤성
입력 CSB 필지 × CDL 연 서열, 가뭄해(예: 2012) 기후 피처. 카운티 수량은 선택
출력 이력 대조, 가뭄해 구별 여부. 수량 열이 없으면 null

본편 검증 장소는 Story County입니다. 수량은 옆축이라 없어도 백테스트는 CDL/CSB만으로 성립합니다.

Prithvi 추론 prithvi_infer

L1화면 S2 (보조)Hylē · 배치
입력 HLS 6밴드 × 3시점, 224×224 칩
출력 13클래스 분할, 필지 다수결, agreement_with_cdl

체크포인트 Prithvi-EO-1.0-100M-multi-temporal-crop-classification (Apache-2.0, 카드 mIoU 0.4269). 추론만 하고 미세조정하지 않습니다. Prithvi-EO-2.0 작물 공개본은 없어 쓰지 않습니다. 요청 경로 GPU 금지. 실패 시 CDL 라벨.

시나리오 이동 scenario_shift

L2화면 S5김윤성(S2S), 김우찬(NEX)
입력 GEOS-S2S-3 월 앙상블, NEX-GDDP-CMIP6 SSP2-4.5/5-8.5 다모델
출력 scenario_climate 분포. 다음 시즌·2030년대

다음 시즌은 GEOS-S2S 아노말리(월 강수 비율, 기온 차)를 표본에 더합니다. 2030년대는 delta method (2031–2040 대비 1985–2014):

\[ \Delta = \overline{X}_{2031\text{–}2040} - \overline{X}_{1985\text{–}2014} \]

필지 정밀 값처럼 표시하지 않습니다(맥락 칸). WeatherNext는 선택 애드온이며 이번 주말 본편 의존이 아닙니다.

LLM tool-call + RAG toolcall · rag_hnsw

L4화면 S6 · /explainHylē · rag/
입력 사용자 질문, FastAPI 도구(get_profile, compare_strategies, 기후, search_evidence)
출력 설명 문장. 모든 숫자는 도구 JSON 경로 각주. 짧은 인용+DOI

RAG는 근거 카드 전용입니다(데이터 탐색용이 아님). 근거가 없으면 insufficient_evidence: true이고 문장을 만들지 않습니다. 임베딩은 pgvector HNSW, 실패 시 pg_trgm 키워드.
