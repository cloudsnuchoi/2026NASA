AI 네 층과 알고리즘

라이브 엔진은 규칙·지수 스코어링 + 몬테카를로 물수지 + CVaR입니다. 강화학습과 미세조정은 하지 않습니다. LLM은 숫자를 만들지 않습니다. MATLAB은 빌드 단계 검증(오프라인)이며 요청 경로에 없습니다.

요약 표는 AI 모델 탭에 있습니다. 이 페이지는 알고리즘 카드·수식입니다.

수식은 model_api/engine.py에 구현된 내용입니다. 우선순위 슬라이더(물·토양·안정성·소득)는 기본 각 0.25이고 가중만 바꿉니다.

AI 네 층

L1 비전

Prithvi 추론만

HLS 6밴드×3시점 → vision_result (20필지, 2024). 라이브 경로 아님(CPU 배치). 2024년 기준 Prithvi 필지 최빈 클래스가 USDA CDL 작물과 같은 필지는 20개 중 19개이고, 필지별 CDL 픽셀 일치율은 0.193–0.997(중앙값 0.934, 평균 0.883)이다. 대부분 옥수수·콩 단작 필지라 일반 정확도가 아니다(모델 카드 aAcc 60.64 %).

L2 예측·시나리오

GEOS-S2S · NEX-GDDP

다음 시즌 GEOS-S2S 앙상블(멤버 10), 2030년대 NEX-GDDP 2모델×2시나리오 delta → county_scenario_year. 분포로만 표시, 결정론적 다년 예보 없음.

L3 시뮬레이션

7축 + MC + CVaR

피처+슬라이더 → 전략 카드 A–D, P10/P50/P90, CVaR. 요청 시 계산(500회, 시드 고정). Python/NumPy, FastAPI.

L4 설명

LLM tool-call (DeepSeek deepseek-flash)

API JSON → 설명 문장. 숫자는 tool JSON 값만, 대응 없는 숫자는 unverified_numbers. 근거 색인 evidence_chunk는 0행이라 인용은 대체 경로(insufficient_evidence: true).

알고리즘 목록

규칙·지수 7축 점수 score7

L3화면 S4Hylē · model_api/
입력 필지·카운티 피처, 작물 특성(문헌 Kc 등), 전략 A–D
출력 축별 점수 0–1, 슬라이더 가중 합, 기준 A 대비 %

일곱 축: 질소 순환, 침식, 유기물, 병해충 차단, 물 사용, 사료 가치, 시장 적합성(수량 옆축은 선택). 확정 kg/ha는 내지 않습니다.

\[ S = \sum_{k=1}^{7} w_k s_k, \quad s_k \in [0,1], \quad \sum_k w_k = 1 \]

reweight: 우선순위 슬라이더(물·토양·회복력·소득/시장)는 가중 \(w_k\)만 바꿉니다. 원점수 \(s_k\)와 분포는 유지합니다. 단일 정답으로 순위를 강제하지 않습니다. 물 제한이면 물 축 가중을 올립니다.

몬테카를로 물수지 wb_mc

L3화면 S4·S5Hylē · 사전계산
입력 POWER 일 기상 1995–2025, SSURGO AWC, FAO-56 \(K_c\)(OpenET로 필지 보정), HLS 맨땅 기간, 시나리오 이동
출력 생육기 물 부족(mm), 스트레스 일수, 겨울 맨땅 일수 → P10/P50/P90

연 단위 재표본 \(N=500\), 시드 고정(run_id에 기록). 모든 전략이 같은 날씨 표본을 씁니다. 일 물수지와 증발산:

\[ SM_t = SM_{t-1} + P_t - ET_{c,t} - R_t, \qquad ET_c = ET_0 \times K_c, \qquad \mathrm{cap} = \mathrm{AWC} \times z_{\mathrm{root}} \]

\(ET_0\)는 FAO-56(fao56, POWER). \(K_c\)는 작물·생육 단계 문헌 범위. 유출은 SCS 곡선번호, 용량을 넘으면 배수 \(R_t\). 물 스트레스는 FAO-56 식입니다.

CVaR와 분위 cvar

L3화면 S4·S5Hylē
입력 몬테카를로 표본(물 부족, 스트레스 일수 등)
출력 P10, P50, P90, 하위 10% 평균(CVaR). 단위는 응답 unit

회복력·꼬리 위험을 봅니다. 하위 10% 평균:

\[ \mathrm{CVaR}_{0.10}(X) = \mathbb{E}\!\left[X \mid X \le q_{0.10}(X)\right] \]

P10/P50/P90은 같은 표본의 경험적 분위입니다. 화면의 %는 “기준 전략 A 대비 상대 지수, 보장값 아님”과 범위를 함께 보여 줍니다.

CDL/CSB 백테스트 backtest_cdl

검증화면 S5 · /validation/backtestHylē, 김윤성
입력 필지 CDL 작물, 실제 2009–2012 POWER 날씨
출력 전략별 2012 생육기 물 부족(mm), 겨울 맨땅 일수

같은 물수지를 실제 2009–2012 날씨로 다시 돌립니다(데모 필지 20개 모두). 예: Story County 필지 191825003869023의 2012 생육기 물 부족은 A 463, B 451, C 366, D 513 mm, 겨울 맨땅 일수는 A 181, B 9, C 3일입니다. 상대 모델 지수이며 수량 약속이 아닙니다.

Prithvi 추론 prithvi_infer

L1화면 S2 (보조)Hylē · 배치
입력 HLS 6밴드 × 3시점, 224×224 칩
출력 13클래스 분할, 필지 다수결, agreement_with_cdl

체크포인트 Prithvi-EO-1.0-100M-multi-temporal-crop-classification (Apache-2.0, 카드 mIoU 0.4269). 추론만 하고 미세조정하지 않습니다. 요청 경로 밖(CPU 배치). 작물 라벨 기준은 CDL입니다.

2024년 기준 Prithvi 필지 최빈 클래스가 USDA CDL 작물과 같은 필지는 20개 중 19개이고, 필지별 CDL 픽셀 일치율은 0.193–0.997(중앙값 0.934, 평균 0.883)이다. 대부분 옥수수·콩 단작 필지라 일반 정확도가 아니다(모델 카드 aAcc 60.64 %). 정의: PRITHVI-AGREEMENT.md.

시나리오 이동 scenario_shift

L2화면 S5김윤성(S2S), 김우찬(NEX)
입력 GEOS-S2S-3 앙상블(멤버 10), NEX-GDDP-CMIP6 ACCESS-CM2·MPI-ESM1-2-HR × SSP2-4.5/5-8.5
출력 /simulate scenario_results 분포. 다음 시즌·2030년대

다음 시즌은 GEOS-S2S 아노말리(월 강수 비율, 기온 차)를 표본에 더합니다. 2030년대는 delta method (2031–2040 대비 1985–2014):

\[ \Delta = \overline{X}_{2031\text{–}2040} - \overline{X}_{1985\text{–}2014} \]

필지 정밀 값처럼 표시하지 않습니다. 예: 같은 Story 필지의 전략 A 물 부족은 과거 표본 P10–P90 115–265 mm, GEOS-S2S 다음 시즌 적용 시 136–309 mm입니다.
